隱私權

Libretta 是一款語音記事本：你可以書寫、說話、錄製會議，App 會為你轉錄並產生摘要。它的設計讓這一切都在你的裝置上完成，並儲存在屬於你的資料夾中。

  • 不需要帳號。我們從不要求你提供姓名、電子郵件或密碼。
  • 沒有我們自己的伺服器。你的筆記、音訊和轉錄文字從不經過我們的伺服器，因為我們沒有伺服器。
  • 你的筆記只屬於你。你書寫、錄製或轉錄的任何內容都不會傳到我們或任何第三方，但你開啟 Private Cloud Compute 後傳送給它的文字除外。沒有廣告，也沒有跨 App 追蹤。

你的筆記存放在哪裡

每則筆記都是一個資料夾，裡面有 Markdown 檔案和對應的音訊。它們依你的選擇儲存在你的裝置上，或儲存在 iCloud Drive 的 Libretta 資料夾中。如果你使用 iCloud Drive，Apple 會依其隱私權政策在你的裝置之間同步這些檔案；我們無法存取它們。你可以隨時在「檔案」App 或 Finder 中開啟、移動或刪除它們。

App 也會在裝置上保留一個搜尋索引和一份快取，讓運作更快速。兩者都可以由你的檔案重新建立，刪除 App 時也會一併刪除。

在你的裝置上處理的內容

  • 轉錄與說話者區分。音訊由在你的裝置上執行的模型轉錄並依說話者劃分：Apple 的語音辨識和 Desert Ant Labs 的模型。
  • 摘要與提問。摘要、決定、任務以及對你提問的回答，都由你裝置上的 Apple Intelligence 撰寫。
  • 搜尋。用於搜尋你筆記的索引在你的裝置上建立與查詢。

使用 Private Cloud Compute 產生摘要（選用）

Libretta 提供一項設定，可以使用 Private Cloud Compute 來產生摘要，它是 Apple 在其伺服器上執行的模型。此設定預設為關閉。如果你開啟它，待摘要的轉錄文字會傳送到 Private Cloud Compute；音訊不會傳送。Apple 將此服務設計為在不儲存請求、也不讓任何人（無論是 Apple 還是我們）看到請求的情況下處理它。App 會標示每一則在你裝置之外產生的摘要，你也可以要求它在傳送文字之前隱藏個人資料。

模型下載

初次使用時，Libretta 會從 Desert Ant Labs 下載轉錄模型，系統會下載 Apple 的語音模型。這些是檔案下載：提供檔案的伺服器與任何下載一樣，會看到你連線的 IP 位址，但不會收到你的任何筆記、音訊或資料。

App 要求的權限

每項權限只會在你使用需要它的功能時才要求，你可以隨時在「設定」中撤銷。

  • 麥克風。用於錄製你的筆記和會議。它只在你要求時錄音，錄音期間會顯示在螢幕上。
  • 行事曆。用於顯示你的會議並將其準備為筆記。iOS 只提供完整取用權限，但 Libretta 只會讀取：從不建立、更改或刪除行程。
  • 聯絡人。用於為會議中的發言者加上姓名和電子郵件。你所選的內容會儲存在你的筆記中。
  • 通知。用於在會議前提醒你。通知會在你的裝置上排程。
  • 系統音訊（Mac）。用於在錄製麥克風的同時錄下視訊通話的聲音。

App 從你的行事曆或聯絡人讀取的任何內容都不會離開你的裝置，但你寫進筆記並同步到 iCloud Drive 的內容除外。

使用統計資料

為了了解哪些功能被使用以及哪裡出了問題，Libretta 會向 TelemetryDeck 傳送匿名使用統計資料，這是一項專為保護隱私權而打造的服務。每個訊號會說明使用了哪個畫面或功能，以及 App 和系統版本、裝置型號和語言。使用者識別碼在傳送前會在你的裝置上進行雜湊處理，TelemetryDeck 不會儲存你的 IP 位址，任何訊號都不包含你的筆記、音訊、轉錄文字、行事曆或聯絡人的內容。這些資料不用於廣告，也不會與其他 App 的資料合併。

購買項目

如果你在 Libretta 中購買內容，付款由 Apple 處理，我們從不會看到你的付款資訊。為了知道你解鎖了什麼，我們使用 RevenueCat，它會收到由 App 建立的匿名識別碼、Apple 提供的購買資訊以及裝置的技術資訊。它不會收到你的姓名、電子郵件或筆記中的任何內容。

當你分享時

如果你匯出或分享筆記、錄音或摘要，它會傳送到你選擇的地方，並受該 App 或服務的條款約束。

當機報告

如果你在裝置設定中同意與 App 開發者分享分析資料，Apple 可能會將 Libretta 的匿名當機報告轉交給我們。報告中不包含你的任何筆記或音訊，你可以在「設定」 › 「隱私權與安全性」 › 「分析與改善」中將其關閉。

兒童

Libretta 不向任何人（包括兒童）索取個人資料，也不以兒童為對象。
