# libretta.app

Web estática de Libretta, servida con GitHub Pages en https://libretta.app.

- `/` y `/en/`: página de inicio.
- `/privacidad/` y `/en/privacy/`: política de privacidad (la URL que va en App Store Connect).

Sin build ni dependencias: HTML, una hoja de estilos y la fuente Instrument Sans autoalojada. Colores y tipografía del sistema de marca de Libretta.
