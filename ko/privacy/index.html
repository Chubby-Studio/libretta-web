2026년 11월 10일 업데이트됨

개인정보 보호

Libretta는 음성 노트북입니다. 글을 쓰고, 말하고, 회의를 녹음하면 앱이 받아쓰기와 요약을 해 줍니다. 이 모든 과정이 사용자의 기기에서 이루어지고, 사용자 소유의 폴더에 저장되도록 만들어졌습니다.

  • 계정이 없습니다. 이름, 이메일, 암호를 요청하지 않습니다.
  • 자체 서버가 없습니다. 노트, 오디오, 받아쓰기 텍스트는 저희 서버를 거치지 않습니다. 저희에게는 서버가 없기 때문입니다.
  • 노트는 오직 사용자의 것입니다. 사용자가 쓰거나 녹음하거나 받아쓴 내용은 저희나 제3자에게 전달되지 않습니다. 다만 Private Cloud Compute를 켠 경우 그곳으로 보내는 텍스트는 예외입니다. 광고도, 앱 간 추적도 없습니다.

노트가 저장되는 곳

각 노트는 Markdown 파일과 오디오가 담긴 폴더입니다. 사용자의 선택에 따라 기기 또는 iCloud Drive의 Libretta 폴더에 저장됩니다. iCloud Drive를 사용하면 Apple이 자체 개인정보 처리방침에 따라 이 파일들을 기기 간에 동기화하며, 저희는 접근할 수 없습니다. 파일 앱이나 Finder에서 언제든지 열고, 옮기고, 삭제할 수 있습니다.

앱은 더 빠르게 동작하도록 기기에 검색 색인과 캐시도 보관합니다. 둘 다 사용자의 파일로 다시 만들 수 있으며 앱을 삭제하면 함께 사라집니다.

기기에서 처리되는 것

  • 받아쓰기와 화자 구분. 오디오는 사용자의 기기에서 실행되는 모델로 텍스트로 변환되고 화자별로 나뉩니다. Apple의 음성 인식과 Desert Ant Labs의 모델을 사용합니다.
  • 요약과 질문. 요약, 결정 사항, 할 일, 질문에 대한 답변은 사용자의 기기에서 Apple Intelligence가 작성합니다.
  • 검색. 노트를 검색할 수 있게 해 주는 색인은 사용자의 기기에서 만들어지고 조회됩니다.

Private Cloud Compute로 요약하기(선택 사항)

Libretta에는 Apple의 서버에서 실행되는 Apple의 모델인 Private Cloud Compute로 요약을 작성하는 설정이 있습니다. 이 설정은 기본적으로 꺼져 있습니다. 켜면 요약할 받아쓰기 텍스트가 Private Cloud Compute로 전송되며, 오디오는 전송되지 않습니다. Apple은 이 서비스가 요청을 저장하지 않고, Apple이든 저희든 누구도 내용을 볼 수 없도록 처리하게 설계했습니다. 앱은 기기 밖에서 작성된 모든 요약에 표시를 하며, 텍스트를 보내기 전에 개인 정보를 가리도록 요청할 수도 있습니다.

모델 다운로드

처음 사용할 때 Libretta는 Desert Ant Labs에서 받아쓰기 모델을 다운로드하고, 시스템은 Apple의 음성 모델을 다운로드합니다. 이는 파일 다운로드입니다. 파일을 제공하는 서버는 다른 모든 다운로드와 마찬가지로 연결의 IP 주소를 볼 수 있지만, 노트, 오디오, 데이터는 전혀 받지 않습니다.

앱이 요청하는 권한

각 권한은 그것이 필요한 기능을 사용할 때만 요청되며, 설정에서 언제든지 철회할 수 있습니다.

  • 마이크. 노트와 회의를 녹음하기 위한 권한입니다. 사용자가 요청할 때만 녹음하며, 녹음하는 동안 화면에 표시됩니다.
  • 캘린더. 회의를 보여 주고 노트로 준비하기 위한 권한입니다. iOS는 전체 접근 권한만 제공하지만, Libretta는 읽기만 하며 이벤트를 만들거나 변경하거나 삭제하지 않습니다.
  • 연락처. 회의에서 말하는 사람에게 이름과 이메일을 붙이기 위한 권한입니다. 선택한 내용은 노트에 저장됩니다.
  • 알림. 회의 전에 알려 드리기 위한 권한입니다. 알림은 사용자의 기기에서 예약됩니다.
  • 시스템 오디오(Mac). 화상 통화 소리를 마이크와 함께 녹음하기 위한 권한입니다.

앱이 캘린더나 연락처에서 읽은 내용은 사용자가 노트에 적어 iCloud Drive에 동기화하는 것을 제외하고는 기기를 벗어나지 않습니다.

사용 통계

어떤 기능이 사용되는지, 무엇이 문제를 일으키는지 알기 위해 Libretta는 개인정보 보호를 위해 만들어진 서비스인 TelemetryDeck에 익명 사용 통계를 보냅니다. 각 신호에는 사용된 화면이나 기능, 앱과 시스템 버전, 기기 모델, 언어가 담깁니다. 사용자 식별자는 전송 전에 사용자의 기기에서 해시 처리되고, TelemetryDeck는 IP 주소를 저장하지 않으며, 어떤 신호에도 노트, 오디오, 받아쓰기 텍스트, 캘린더, 연락처의 내용은 담기지 않습니다. 이 통계는 광고에 사용되지 않으며 다른 앱의 데이터와 결합되지 않습니다.

구입

Libretta에서 무언가를 구입하면 결제는 Apple이 처리하며, 저희는 결제 정보를 절대 보지 않습니다. 무엇을 잠금 해제했는지 확인하기 위해 RevenueCat을 사용합니다. RevenueCat은 앱이 만든 익명 식별자, Apple이 제공하는 구입 정보, 기기의 기술적 세부 정보를 받습니다. 이름, 이메일, 노트의 어떤 내용도 받지 않습니다.

공유할 때

노트, 녹음, 요약을 내보내거나 공유하면, 사용자가 선택한 곳으로 해당 앱이나 서비스의 약관에 따라 전달됩니다.

충돌 보고서

기기 설정에서 앱 개발자와 분석 정보를 공유하는 데 동의하면, Apple이 Libretta의 익명 충돌 보고서를 저희에게 전달할 수 있습니다. 여기에는 노트나 오디오가 전혀 포함되지 않으며, 설정 › 개인정보 보호 및 보안 › 분석 및 향상에서 끌 수 있습니다.

어린이

Libretta는 어린이를 포함해 누구에게도 개인 정보를 요청하지 않으며, 어린이를 대상으로 하지 않습니다.

이 웹사이트

libretta.app은 쿠키, 분석 도구, 제3자 리소스를 사용하지 않습니다. GitHub Pages에서 제공되며, GitHub Pages는 보안을 위해 개인정보 보호 정책에 따라 방문 기록을 남깁니다.
