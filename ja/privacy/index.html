プライバシー

Librettaは音声ノートです。書く、話す、会議を録音すると、Appが文字起こしと要約を行います。これらすべてがお使いのデバイス上で行われ、お客様自身のフォルダに保存されるように作られています。

  • アカウントは不要です。お名前、メールアドレス、パスワードをお尋ねすることはありません。
  • 独自のサーバはありません。ノート、オーディオ、文字起こしが当社のサーバを経由することはありません。サーバを持っていないからです。
  • ノートはお客様だけのものです。書いたもの、録音したもの、文字起こししたものが、当社や第三者に届くことはありません。ただし、Private Cloud Computeをオンにした場合に送信されるテキストは除きます。広告も、Appをまたぐトラッキングもありません。

ノートの保存場所

各ノートは、Markdownファイルとそのオーディオを収めたフォルダです。お選びいただいた場所に応じて、お使いのデバイス、またはiCloud DriveのLibrettaフォルダに保存されます。iCloud Driveをお使いの場合、これらのファイルはAppleのプライバシーポリシーに従ってAppleがデバイス間で同期します。当社はそれらにアクセスできません。ファイルは、ファイルAppやFinderからいつでも開いたり、移動したり、削除したりできます。

Appは、動作を速くするために、検索インデックスとキャッシュもデバイス上に保持します。どちらもファイルから再構築され、Appを削除すると消えます。

デバイス上で処理されるもの

  • 文字起こしと話者の識別。オーディオの文字起こしと話者の分離は、お使いのデバイス上で動作するモデルで行われます。Appleの音声認識と、Desert Ant Labsのモデルです。
  • 要約と質問。要約、決定事項、タスク、ご質問への回答は、お使いのデバイス上でApple Intelligenceが作成します。
  • 検索。ノートを検索するためのインデックスは、お使いのデバイス上で作成され、照会されます。

Private Cloud Computeによる要約（任意）

Librettaには、Appleのサーバ上で動作するAppleのモデルであるPrivate Cloud Computeで要約を作成する設定があります。この設定はデフォルトではオフです。オンにすると、要約する文字起こしのテキストがPrivate Cloud Computeに送信されます。オーディオは送信されません。Appleは、このサービスがリクエストを保存せず、Appleも当社も誰も内容を見ることができない形で処理するように設計しています。Appは、デバイス外で作成された要約すべてに印を付け、テキストを送信する前に個人データを隠すよう指定することもできます。

モデルのダウンロード

初めてお使いになるとき、LibrettaはDesert Ant Labsから文字起こしモデルをダウンロードし、システムがAppleの音声モデルをダウンロードします。これらはファイルのダウンロードです。配信するサーバは、どのダウンロードとも同じように接続元のIPアドレスを認識しますが、ノート、オーディオ、データは一切受け取りません。

Appが求める許可

各許可は、それを必要とする機能をお使いになるときにのみ求められ、設定からいつでも取り消せます。

  • マイク。ノートや会議を録音するためです。録音するのはお客様が操作したときだけで、録音中は画面に表示されます。
  • カレンダー。会議を表示し、ノートとして準備するためです。iOSでは完全アクセスしか選べませんが、Librettaは読み取るだけで、イベントの作成、変更、削除は一切行いません。
  • 連絡先。会議で話す人に名前とメールアドレスを付けるためです。選んだ内容はノートに保存されます。
  • 通知。会議の前にお知らせするためです。通知はお使いのデバイス上でスケジュールされます。
  • システムオーディオ（Mac）。ビデオ通話の音声をマイクの音声と一緒に録音するためです。

Appがカレンダーや連絡先から読み取った内容は、お客様がノートに書いてiCloud Driveに同期するもの以外、デバイスの外に出ることはありません。

利用統計

どの機能が使われているか、何が不具合を起こしているかを知るため、Librettaはプライバシーを重視して作られたサービスであるTelemetryDeckに匿名の利用統計を送信します。各シグナルには、使われた画面や機能に加えて、Appとシステムのバージョン、デバイスのモデル、言語が含まれます。ユーザ識別子は送信前にお使いのデバイス上でハッシュ化され、TelemetryDeckはIPアドレスを保存せず、ノート、オーディオ、文字起こし、カレンダー、連絡先の内容がシグナルに含まれることはありません。これらは広告には使われず、他のAppのデータと組み合わされることもありません。

購入

Librettaで何かを購入すると、支払いはAppleが処理し、当社が支払いの詳細を目にすることはありません。何を購入済みかを把握するため、RevenueCatを利用しています。RevenueCatが受け取るのは、Appが作成した匿名の識別子、Appleが提供する購入情報、デバイスの技術的な詳細です。お名前、メールアドレス、ノートの内容は受け取りません。

共有するとき

ノート、録音、要約を書き出したり共有したりすると、お客様が選んだ送信先に、そのAppやサービスの規約に従って渡されます。

クラッシュレポート

デバイスの設定で、Appデベロッパとの解析の共有に同意している場合、AppleがLibrettaの匿名のクラッシュレポートを当社に渡すことがあります。そこにノートやオーディオは含まれません。設定 › プライバシーとセキュリティ › 解析と改善でオフにできます。

お子様

Librettaは、お子様を含め、誰にも個人データを求めません。また、お子様向けのものではありません。

このウェブサイト

libretta.appは、Cookie、アナリティクス、第三者のリソースを使用していません。GitHub Pagesから配信されており、GitHub Pagesはセキュリティのためにアクセスを記録します。詳しくはプライバシーに関する声明をご覧ください。
