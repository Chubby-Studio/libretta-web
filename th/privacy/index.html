ความเป็นส่วนตัว

Libretta คือสมุดบันทึกเสียง: คุณเขียน พูด และบันทึกการประชุม แล้วแอปจะถอดเสียงและสรุปให้ แอปถูกสร้างมาให้ทั้งหมดนี้เกิดขึ้นบนอุปกรณ์ของคุณ และเก็บไว้ในโฟลเดอร์ที่เป็นของคุณ

  • ไม่มีบัญชี เราไม่เคยขอชื่อ อีเมล หรือรหัสผ่านจากคุณ
  • ไม่มีเซิร์ฟเวอร์ของเราเอง โน้ต เสียง และข้อความถอดเสียงของคุณไม่เคยผ่านเซิร์ฟเวอร์ของเรา เพราะเราไม่มีเซิร์ฟเวอร์
  • โน้ตเป็นของคุณคนเดียว ไม่มีสิ่งใดที่คุณเขียน บันทึก หรือถอดเสียงไปถึงเราหรือบุคคลที่สาม ยกเว้นข้อความที่คุณส่งไปยัง Private Cloud Compute หากคุณเปิดใช้ ไม่มีโฆษณา และไม่มีการติดตามข้ามแอป

โน้ตของคุณอยู่ที่ไหน

โน้ตแต่ละรายการคือโฟลเดอร์ที่มีไฟล์ Markdown และไฟล์เสียงของโน้ตนั้น โน้ตจะถูกเก็บไว้บนอุปกรณ์ของคุณหรือในโฟลเดอร์ Libretta ใน iCloud Drive ตามที่คุณเลือก หากคุณใช้ iCloud Drive Apple จะซิงค์ไฟล์เหล่านั้นข้ามอุปกรณ์ของคุณภายใต้นโยบายความเป็นส่วนตัวของ Apple เราไม่สามารถเข้าถึงไฟล์เหล่านั้นได้ คุณเปิด ย้าย หรือลบไฟล์ได้ทุกเมื่อจากแอปไฟล์หรือ Finder

แอปยังเก็บดัชนีการค้นหาและแคชไว้บนอุปกรณ์เพื่อให้ทำงานเร็วขึ้น ทั้งสองอย่างสร้างขึ้นใหม่ได้จากไฟล์ของคุณ และจะหายไปเมื่อคุณลบแอป

สิ่งที่ประมวลผลบนอุปกรณ์ของคุณ

  • การถอดเสียงและการแยกเสียงผู้พูด เสียงถูกถอดเป็นข้อความและแยกตามผู้พูดด้วยโมเดลที่ทำงานบนอุปกรณ์ของคุณ ได้แก่การรู้จำเสียงพูดของ Apple และโมเดลจาก Desert Ant Labs
  • บทสรุปและคำถาม บทสรุป การตัดสินใจ งาน และคำตอบสำหรับคำถามของคุณ เขียนโดย Apple Intelligence บนอุปกรณ์ของคุณ
  • การค้นหา ดัชนีที่ทำให้คุณค้นหาโน้ตได้ ถูกสร้างและสืบค้นบนอุปกรณ์ของคุณ

สรุปด้วย Private Cloud Compute (ไม่บังคับ)

Libretta มีการตั้งค่าให้เขียนบทสรุปด้วย Private Cloud Compute ซึ่งเป็นโมเดลของ Apple ที่ทำงานบนเซิร์ฟเวอร์ของ Apple การตั้งค่านี้ปิดอยู่โดยค่าเริ่มต้น หากคุณเปิดใช้ ข้อความถอดเสียงที่จะสรุปจะถูกส่งไปยัง Private Cloud Compute ส่วนเสียงจะไม่ถูกส่ง Apple ออกแบบบริการนี้ให้ประมวลผลคำขอโดยไม่จัดเก็บ และโดยที่ไม่มีใคร ทั้ง Apple และเรา มองเห็นได้ แอปจะทำเครื่องหมายบนบทสรุปทุกรายการที่เขียนนอกอุปกรณ์ของคุณ และคุณสามารถให้แอปซ่อนข้อมูลส่วนบุคคลก่อนส่งข้อความได้

การดาวน์โหลดโมเดล

เมื่อใช้งานครั้งแรก Libretta จะดาวน์โหลดโมเดลถอดเสียงจาก Desert Ant Labs และระบบจะดาวน์โหลดโมเดลเสียงพูดของ Apple นี่คือการดาวน์โหลดไฟล์ เซิร์ฟเวอร์ที่ส่งไฟล์จะเห็นที่อยู่ IP ของการเชื่อมต่อของคุณ เหมือนกับการดาวน์โหลดทั่วไป แต่ไม่ได้รับโน้ต เสียง หรือข้อมูลใด ๆ ของคุณ

สิทธิ์ที่แอปขอ

แอปจะขอสิทธิ์แต่ละอย่างเมื่อคุณใช้ฟีเจอร์ที่ต้องการสิทธิ์นั้นเท่านั้น และคุณเพิกถอนได้ทุกเมื่อในการตั้งค่า

  • ไมโครโฟน เพื่อบันทึกโน้ตและการประชุมของคุณ แอปจะบันทึกเมื่อคุณสั่งเท่านั้น และแสดงบนหน้าจอขณะบันทึก
  • ปฏิทิน เพื่อแสดงการประชุมของคุณและเตรียมเป็นโน้ต iOS ให้สิทธิ์เข้าถึงแบบเต็มเท่านั้น แต่ Libretta อ่านอย่างเดียว: ไม่สร้าง แก้ไข หรือลบกิจกรรมเลย
  • รายชื่อ เพื่อใส่ชื่อและอีเมลให้ผู้พูดในการประชุม สิ่งที่คุณเลือกจะถูกบันทึกในโน้ตของคุณ
  • การแจ้งเตือน เพื่อเตือนคุณก่อนการประชุม การแจ้งเตือนถูกตั้งเวลาไว้บนอุปกรณ์ของคุณ
  • เสียงของระบบ (Mac) เพื่อบันทึกเสียงของการโทรวิดีโอพร้อมกับไมโครโฟนของคุณ

ไม่มีสิ่งใดที่แอปอ่านจากปฏิทินหรือรายชื่อของคุณออกจากอุปกรณ์ ยกเว้นสิ่งที่คุณเขียนในโน้ตและซิงค์ไปยัง iCloud Drive ของคุณ

สถิติการใช้งาน

เพื่อให้ทราบว่าฟีเจอร์ใดถูกใช้และอะไรที่ทำงานผิดพลาด Libretta ส่งสถิติการใช้งานแบบไม่ระบุตัวตนไปยัง TelemetryDeck ซึ่งเป็นบริการที่สร้างมาเพื่อความเป็นส่วนตัว สัญญาณแต่ละรายการบอกว่ามีการใช้หน้าจอหรือฟีเจอร์ใด พร้อมเวอร์ชันของแอปและระบบ รุ่นอุปกรณ์ และภาษา ตัวระบุผู้ใช้ถูกแฮชบนอุปกรณ์ของคุณก่อนส่ง TelemetryDeck ไม่จัดเก็บที่อยู่ IP ของคุณ และไม่มีสัญญาณใดที่มีเนื้อหาของโน้ต เสียง ข้อความถอดเสียง ปฏิทิน หรือรายชื่อของคุณ สถิติเหล่านี้ไม่ถูกใช้เพื่อโฆษณาและไม่ถูกนำไปรวมกับข้อมูลจากแอปอื่น

การซื้อ

หากคุณซื้อสิ่งใดใน Libretta Apple เป็นผู้จัดการการชำระเงิน และเราไม่เคยเห็นรายละเอียดการชำระเงินของคุณ เพื่อให้ทราบว่าคุณปลดล็อกอะไรไปแล้ว เราใช้ RevenueCat ซึ่งได้รับตัวระบุแบบไม่ระบุตัวตนที่แอปสร้างขึ้น ข้อมูลการซื้อที่ Apple ให้มา และรายละเอียดทางเทคนิคของอุปกรณ์ โดยไม่ได้รับชื่อ อีเมล หรือสิ่งใดจากโน้ตของคุณ

เมื่อคุณแชร์

หากคุณส่งออกหรือแชร์โน้ต การบันทึก หรือบทสรุป สิ่งนั้นจะไปยังที่ที่คุณเลือก ภายใต้เงื่อนไขของแอปหรือบริการนั้น

รายงานข้อขัดข้อง

หากคุณยินยอมในการตั้งค่าอุปกรณ์ให้แชร์ข้อมูลวิเคราะห์กับนักพัฒนาแอป Apple อาจส่งรายงานข้อขัดข้องแบบไม่ระบุตัวตนของ Libretta มาให้เรา รายงานเหล่านี้ไม่มีโน้ตหรือเสียงของคุณเลย และคุณปิดได้ที่การตั้งค่า › ความเป็นส่วนตัวและความปลอดภัย › การวิเคราะห์และการปรับปรุง

เด็ก

Libretta ไม่ขอข้อมูลส่วนบุคคลจากใคร รวมถึงเด็ก และไม่ได้มุ่งเป้าไปที่เด็ก

เว็บไซต์นี้

libretta.app ไม่ใช้คุกกี้ การวิเคราะห์ หรือทรัพยากรจากบุคคลที่สาม เว็บไซต์ให้บริการผ่าน GitHub Pages ซึ่งบันทึกการเข้าชมเพื่อความปลอดภัยตามแถลงการณ์ความเป็นส่วนตัวของ GitHub
